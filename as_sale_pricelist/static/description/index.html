Lista de Precios por Línea de Productos en Ventas

Este módulo extiende la funcionalidad estándar de listas de precios de Odoo para permitir la selección de listas de precios específicas a nivel de línea de pedido, con sistema de promociones y cálculo automático de márgenes en múltiples monedas.

Características Principales

Selección de listas de precios específicas para cada línea de pedido.

Aplicación de promociones y programas de lealtad por línea.

Cálculo automático de márgenes y utilidades por línea.

Conversión automática de precios entre monedas (MXN/USD).

Control de cantidades máximas por promoción.

Validación de márgenes mínimos y globales.

Historial completo de promociones aplicadas.

Requisitos y Configuración

Requisitos del Sistema
  • Odoo 18 Enterprise
  • Módulos base, sale_management, product, account, sale_margin, y otros módulos dependientes
Configuración Inicial
  • Crear listas de precios en Ventas > Configuración > Listas de Precios
  • Configurar programas de lealtad en Ventas > Configuración > Programas de Lealtad

Botón 'Precios' para cada línea de producto en la orden de venta
